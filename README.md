# بوت «تحضيرية» 🩺 — Mini App لطلاب السنة التحضيرية السورية

تطبيق ويب مصغّر داخل تيليجرام بدورين:

**🎓 الطالب:** مكتبة ملفات مصنّفة (نوط/دورات/سلالم/كتب حسب المادة والمصدر) مع بحث وتحميل عبر البوت،
حصص دراسية قادمة مع انضمام وتذكير تلقائي، تذكيرات شخصية بأوقات يحددها الطالب،
جدول يومي، مهام مع سلسلة التزام، مؤقت بومودورو، اختبار MCQ يومي، وعدّاد للمحطات
(امتحانات الفصلين ثم مفاضلة الفرز — تواريخ تقريبية تُحدَّث رسمياً).

**🛠️ الأدمن:** لوحة تحكم عبر `/admin` في محادثة البوت + تبويب «أدمن» في التطبيق:
إضافة ملفات للمكتبة (إرسال الملف في المحادثة ثم تصنيفه: مادة ← نوع ← مصدر/سنة)،
جدولة حصص دراسية مع إشعار تلقائي للطلاب وتذكير قبل الموعد، إرسال إعلانات جماعية،
إحصائيات وحذف ملفات/حصص.

## المتغيرات (كل الأسرار من البيئة فقط — لا تُكتب في الملفات)

| المتغير | الوصف |
|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather (إجباري) |
| `WEBAPP_URL` | رابط HTTPS العام للتطبيق (إجباري للـ Mini App) |
| `ADMIN_IDS` | معرّفات تيليجرام للأدمن مفصولة بفواصل، مثال: `123456789,987654321` |
| `DB_PATH` | مسار قاعدة البيانات (اختياري) |
| `DEV_MODE=1` | تجربة الواجهة محلياً بدون تيليجرام (للتطوير فقط) |

## التشغيل محلياً

```bash
cd ~/workspace/baccalaureate-bot/tahdiriya
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# تجربة الواجهة فقط (بدون بوت):
DEV_MODE=1 .venv/bin/uvicorn backend.main:app --port 8000

# التشغيل الكامل:
BOT_TOKEN=... WEBAPP_URL=https://... ADMIN_IDS=123456789 \
  .venv/bin/uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

## النشر (استضافات مجانية لا تطلب بطاقة بنكية)

الـ Mini App يحتاج رابط **HTTPS عام** (شرط تيليجرام). خيارات مجانية موثقة بلا بطاقة:
- **VisiHost** — حاويات Python مجانية 24/7، التسجيل عبر Discord (الأنسب).
- **Raven Host** — مجاني دائم، 512MB.
- **FadeHost** — أول بوت مجاني.

البوت يعمل بنمط polling — لا يحتاج نطاقاً خاصاً به، فقط رابط HTTPS للواجهة.

## ما يلزم للانطلاق

1. بوت جديد عبر `@BotFather` ← `/newbot` (الاسم: تحضيرية).
2. `BOT_TOKEN` من BotFather.
3. رابط `WEBAPP_URL` بعد النشر على إحدى الاستضافات.
4. `ADMIN_IDS`: معرّف تيليجرام للشخص الأدمن (يظهر عند مراسلة `@userinfobot`).
5. في BotFather ← إعدادات البوت ← Menu Button ← ضع رابط التطبيق (أو يكفي زر `/app` داخل البوت).

## ملاحظات

- التوكن لا يُطبع في أي سجل ولا يُحفظ في أي ملف.
- تُحفظ `file_id` الخاصة بتيليجرام فقط — لا تُخزَّن بايتات الملفات محلياً.
- تواريخ الامتحانات/الفرز تقريبية (دفعة 2026-2027) — حدّثها في `backend/config.py` عند صدور البرامج الرسمية.
- `DEV_MODE=1` للتجربة المحلية فقط ويجب ألا يُفعَّل إنتاجياً.
